# EM3 無障礙自評

目標：**WCAG 2.1 AA** 與 **臺灣網站無障礙規範（110.07 版）檢測等級 AA**，也就是規範中 30 個 A 級加 20 個 AA 級成功準則。這份文件記錄符合範圍、檢測方法、逐項結果，以及還需要人工或官方工具確認的地方。自評日期：2026-10-18。

## 符合範圍

| 範圍內                                               | 範圍外（原因）                                                                                   |
| ---------------------------------------------------- | ------------------------------------------------------------------------------------------------ |
| EM3 的所有頁面：介紹、登入、App 內 20 個路由         | **E3 提供的內容**：老師上傳的 PDF、影片、公告 HTML、作業說明。EM3 原樣呈現，無法替它補字幕或標記 |
| 介面語言：繁體中文、English、日本語                  | **Emoji 語言**：使用者主動選擇的趣味版本，不是符合版本；三種文字語言隨時可從設定或語言選單切回   |
| 主題：EM3 淺色、EM3 深色（「跟隨系統」時就是這兩個） | **其他 35 個 daisyUI 主題**：使用者自選的替代外觀，未逐一調整對比                                |
| 預設的 14 種課程顏色                                 | **自訂課程顏色**：使用者自己挑的顏色，EM3 會混色提高對比，但不保證任意顏色都達標                 |
|                                                      | 交給 E3 完成的頁面（點「前往 Moodle」之後）                                                      |

## 檢測方法

1. **自動檢測**：[axe-core](https://github.com/dequelabs/axe-core) 4.10.3，規則集 `wcag2a`、`wcag2aa`、`wcag21a`、`wcag21aa` 加 `best-practice`。用全域安裝的 Playwright 以測試帳號登入後逐頁執行；所有可能改變 E3 狀態的請求都在瀏覽器層攔截。
2. **臺灣檢測碼補充檢查**（axe 不涵蓋的部分，同一支腳本執行）：
   - CS2140401C：所有樣式表裡的 `font-size` 不得使用 px。
   - HM1130100C：可見標頭不得跳級；每頁要有 `<h1>`。
   - `target="_blank"` 的連結要告知會另開新分頁（臺灣稽核常見要求，對應 3.2.5 精神）。
3. **鍵盤腳本**：跳到主要內容、快速跳轉（combobox）、快捷鍵對話框、Esc 關閉、語言切換後焦點回復、關閉單鍵快捷鍵後的行為，共 12 項。
4. **流動排版**：320 CSS px 寬（等同 1280 px 放大 400%），英文與日文各 16 頁，檢查有無水平捲動。
5. **文字間距**：套用 WCAG 1.4.12 的行高 1.5、字距 0.12em、詞距 0.16em、段距 2em，目視檢查裁切與重疊。

測試頁面（22 個）：介紹、登入、今天、待辦、行事曆、公告、信件、課程、課表、設定、課程頁四個分頁、作業、公告討論、測驗、教學分頁、評分、發布公告、小考出題、寫教材。

## 全站作法

- **語言**：`<html lang>` 跟著介面語言（`zh-Hant-TW`、`en`、`ja`）。和介面語言不同的課名、學校英文名、語言選單裡的語言名稱都另外標 `lang`。
- **標題**：每頁 `<title>` 寫出頁面名稱，例如「教材 · 演算法概論 · EM3」；每頁一個 `<h1>`，下面是 `<h2>`、`<h3>`，不跳級。
- **導覽**：側欄與手機底部列是具名的 `<nav>`，目前頁面標 `aria-current="page"`；每頁第一個 Tab 停在「跳到主要內容」；換頁後焦點移到 `<main>`。
- **圖示**：Phosphor 圖示透過 `IconContext` 預設 `aria-hidden`；只有圖示的按鈕和連結都有 `aria-label`。
- **對話框**：原生 `<dialog>` 加 `showModal()`，有焦點限制和 Esc；以 `aria-labelledby` 指向對話框標題；關閉後焦點回到開啟它的按鈕。
- **狀態訊息**：已儲存、已複製、上傳進度、搜尋結果數量放在一直存在的 `role="status"`，錯誤放在 `role="alert"`。
- **對比**：EM3 淺色主題的 success、info、warning、error 調到 4.5:1；次要文字透明度至少 65%；daisyUI 的 `.label` 改為 70%；表單邊框 50%、核取方塊與開關 55%，達 3:1；placeholder 60%。課程顏色當文字時用 `courseText`（和文字色各半），當圖示時用 `courseInk`，實心色塊上的字由 `readableOn` 選黑或白。
- **字級**：全站使用 rem / em；第三方的 Milkdown 與 KaTeX 樣式表在建置時由 PostCSS 把 px 字級換成等值的 rem（`vite.config.ts`）。
- **動畫**：跟隨 `prefers-reduced-motion`；設定裡的「減少動畫」同時停用 motion、CSS 動畫與 transition；持續的閃動（上課中、現在這堂課）只在允許動畫時播放。
- **快捷鍵**：單鍵快捷鍵可以在「設定 → 個人」關閉；有修飾鍵的（`⌘K`、`⌘/`、`⌘↵`）不受影響。

## 還沒做的事

申請標章前還需要：

1. **官方檢測工具**：用 Freego 或數位發展部指定的檢測工具跑一次。EM3 是單頁應用程式，畫面由 JavaScript 產生；如果工具只讀靜態 HTML，需要和認證機構確認檢測方式。
2. **螢幕報讀器實測**：用 NVDA（Windows）與 VoiceOver（macOS、iOS）走一遍登入、看待辦、繳交作業、評分。這次只做了 axe 與鍵盤腳本，沒有實際用報讀器操作。
3. **W3C HTML 驗證**（4.1.1、HM1410100C）。
4. **Milkdown 的懸浮內容**（1.4.13）：人工確認選取工具列與連結提示可以懸停、可以關閉。
5. **HM1130102C 的嚴格解讀**：規範要求表單控制元件以欄位組分群。設定頁、評分、出題的表單都已分群，但單獨的搜尋框沒有包在 `fieldset` 裡；官方工具如果照字面檢查，可能會列出這些搜尋框。
6. **標章與無障礙聲明**：取得認證後，依規定在頁面放置標章與說明。
