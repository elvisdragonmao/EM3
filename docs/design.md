# EM3 設計說明

EM3 是 NYCU E3 的第三方客戶端，純靜態 React SPA。這份文件說明每個設計決定對應到[研究](research/README.md)裡的哪個問題。

## 資訊架構：四個名詞

E3 有十幾個互相重疊的入口。EM3 只用學生每天會講的四個詞，每個詞只出現在一個地方：

| EM3  | 內容                                                 | 取代 E3 的                             |
| ---- | ---------------------------------------------------- | -------------------------------------- |
| 今天 | 現在這堂課、這週行事曆、即將截止、最近教材、最新公告 | 焦點綜覽、當期課程、未來事件、最新公告 |
| 待辦 | 所有本學期作業與測驗，依狀態分組                     | 作業列表、試卷列表、通知鈴             |
| 公告 | 跨課程公告收件匣，本地已讀狀態                       | 公告列表、公告區塊、討論區列表         |
| 課程 | 學期下拉選單 + 課程卡片                              | 我的課程、歷年課程、課程概觀           |

另外兩個輔助頁是行事曆和課表，再加上設定。

課程頁固定四個分頁：**教材 · 作業 · 公告 · 成績**，對應 E3 側欄的教材列表、作業列表＋試卷列表、公告列表＋討論區列表、成績。

## 首頁

由上到下依「下一步要做什麼」排序：

1. **一句話摘要**：「接下來 7 天有 3 份要交，1 份已逾期但還能補交。最近的是 機率・HW 1（今天 23:59）。」不用捲動就知道今天的狀況。
2. **現在這堂課**：依課表判斷正在上（開始前 15 分鐘起算）或下一堂的課，大卡片加上教材、作業、公告三個捷徑，還有上課進度條。這堂課開放中的作業或課堂練習直接列在卡片裡，附「繳交」按鈕。
3. **行事曆**：預設本週，可切換兩週、月。每個截止時間都用課程顏色標示並寫出課名，交過的會劃掉並打勾。格子上方的細線是課表上當天的課。手機上改成圓點，點日期看當天清單。
4. **即將截止**：逾期可補交 → 今天 → 明天 → 之後 → 沒有截止日，附倒數。
5. **最近更新的教材**：本學期所有課的新檔案，點了直接在 App 裡預覽。
6. **最新公告**：課名、相對時間、未讀圓點、作者與摘要。

## 時間的寫法

所有時間都用一套規則（`src/lib/time/relative.ts`）：

- 過去：`剛剛`、`12 分鐘前`、`今天 14:30`、`昨天 星期三`、`前天 星期二`、`星期一`（本週）、`10/5 上星期五`、更早只寫 `9/21`，跨年加年份。
- 未來：`今天 23:59`、`明天 星期四 23:59`、`星期六 23:59`、`下星期二 10/20 23:59`、更遠寫 `11/3 週二 23:59`。
- **`00:00` 截止一律顯示成前一天的 `24:00`**，行事曆也放在前一天。
- 滑鼠移上去會顯示完整日期與「台北時間」。

## 課程辨識

- **顏色與圖示**：每門課依名稱自動挑一個 Phosphor 圖示（演算法 → 形狀、網路 → 樹狀結構、機率 → 骰子…），顏色依課程 ID 固定。點課程頁的圖示可以改顏色、圖示和簡稱（例如把「多媒體與人機互動總整與實作」改成「HCI」），也可以置頂或隱藏。
- **課名解析**：`1151.515505.演算法概論 Introduction to Algorithms` 解析成學期 115 上、課號 515505、中文名、英文名。微學分去掉 `ICT微學分課程_` 前綴；線上課程與其他課程分開歸類。
- **學期下拉選單**：預設本學期，選項附課程數；另有微學分、線上課程、全部、已隱藏。搜尋框會跨所有學期搜尋。

## 課表

E3 沒有上課時間，課程綱要系統的 API 又送出重複的 `Access-Control-Allow-Origin`，瀏覽器會拒絕，所以沒辦法自動抓。課表頁提供三種輸入方式：

- 直接輸入課綱上的時間代碼（`T34R7-EC022`），自動解析成節次和教室。
- 每門課旁邊有連結，直接打開那門課的課綱查時間。
- 選一門課當畫筆，點格子畫上去。

節次時間採用陽明交大的 y z 1 2 3 4 n 5 6 7 8 9 a b c d。

## 教材

- **攤平資料夾**：只有一個檔案的資料夾直接顯示成檔案，資料夾名稱當作副標；多個檔案才顯示成群組。
- **預設最新的在上面**，可以切回老師的順序；老師真的有用週次區段時，才依區段分組。
- **新檔案**：7 天內的檔案標 NEW。
- **預覽**：PDF、圖片、影片在桌機用右側滑出面板預覽。PDF 先讀成 blob 再顯示，避開 E3 回應的 CSP；手機則直接用系統的檢視器開新分頁。每個檔案都有下載按鈕。
- **說明頁**：空資料夾的 intro（Drive 連結、嵌入影片）透過 `mod_folder_get_folders_by_courses` 取得並顯示。
- **E3 專屬模組**：`supervideo` 等 EM3 無法播放的模組，標示成「在 E3 播放」。

## 繳交

一個面板完成：**拖檔案進來 → 確認 → 繳交**。

- 允許的檔案類型、數量與大小寫在拖放區裡，選檔時就檢查。
- 原本交過的檔案預設保留，可以取消勾選。Moodle 的繳交會整批取代，所以保留的檔案會先從 E3 下載再一起重新上傳。
- 按鈕叫「繳交」或「更新繳交」。確認視窗列出繳交後 E3 上會有哪些檔案；逾期時會提醒這次會被標示為遲交。
- 有開草稿的作業會在儲存後自動呼叫 `mod_assign_submit_for_grading`，有繳交聲明時會顯示勾選框。
- 沒有檔案挑選器的各種來源、作者欄或授權選項。

> 開發過程沒有用真實帳號按過「確定繳交」。流程測到確認視窗為止，實際送出需要用測試作業驗證。

## 狀態與資料

| 資料                                                             | 存放位置                                                                               |
| ---------------------------------------------------------------- | -------------------------------------------------------------------------------------- |
| E3 token                                                         | cookie `em3_session`（`SameSite=Strict`，勾選「保持登入」時 90 天，否則 1 天）         |
| 個人設定（語言、主題、課程外觀、課表、已讀公告、預設學期、稱呼） | `localStorage` 的 `em3:prefs`，可在設定頁匯出、匯入 JSON                               |
| E3 回應快取                                                      | IndexedDB，由 React Query persister 管理，開啟時先顯示上次的資料再背景更新，登出時清除 |

多個課程的請求透過 `tool_mobile_call_external_functions` 合併成一次 HTTP 請求，包括繳交狀態、公告和課程內容，所以首頁約 9 個 API 請求就能載完（網站資訊、課程、作業、測驗、繳交狀態、討論區、公告、教材、信件未讀數）。

## 動態與主題

- **動畫**：motion 的 spring（stiffness 380、damping 34）。分頁指示器與側欄選取狀態用 `layoutId` 平滑移動；行事曆切換時依方向滑動；列表依序浮現；預覽面板從右側滑入。設定裡可以減少動畫，也會跟隨系統的 `prefers-reduced-motion`。
- **主題**：daisyUI 5 的 35 個內建主題，加上 EM3 自己的淺色和深色主題，主色取自 logo 的紫色與琥珀色。預設跟隨系統的深淺色。
- **字型**：MiSans TC，從 `font.emtech.cc` 載入；載入前或失敗時用系統的 sans-serif。
- **圖示**：Phosphor Icons。導覽列選取時用 fill，課程圖示用 duotone。

## 語言

介面有繁體中文、English、日本語和 Emoji 四種。預設跟隨瀏覽器的語言清單（`zh*` → 繁中、`ja*` → 日文，其他都用英文），設定頁可以改，登入頁和介紹頁右上角也有語言選單。

- **字典跟著功能放。** 每個 feature 有自己的 `messages.ts`，用 `src/i18n` 的 `defineMessages` 宣告；繁中是來源，其他語言少一個 key、參數型別不同，`tsc` 就會報錯。延遲載入的頁面只帶自己的字串。
- **切換語言時重新掛載整個 App。** 目前語言是模組變數，`<I18nRoot>` 以語言為 key 重新掛載，所以元件、hook、helper 裡直接呼叫 `t()` 都會拿到新語言。React Query 的快取在邊界外，切換時不會重新抓資料；焦點會回到原本的語言選項。
- **E3 的資料不翻譯。** 課名、公告、教材是 E3 的內容；比對 E3 回應用的中文字串（例如 `ICT微學分課程_`、Moodle 的作答狀態）保持原樣。英文介面優先顯示課程的英文名稱。
- **時間的寫法各語言自己來。** 英文用 `Tomorrow 23:59`、`Last Friday, 10/5`，日文用 `明日 木曜日 23:59`；Emoji 版的星期用日文曜日的元素：🌞🌙🔥💧🌳🪙🪐。`00:00` 截止改寫成 `24:00` 的規則在每種語言都適用。
- **Emoji 版**只用 emoji 加上必要的數字、時間和 E3 的內容。它是玩笑性質的替代版本，不列入無障礙符合範圍；`<html lang>` 用系統語言，讓螢幕報讀器用熟悉的語音念 emoji 名稱。

## 鍵盤與無障礙

以 WCAG 2.1 AA 與臺灣網站無障礙規範（110.07 版）AA 等級為目標，逐項自評見 [accessibility.md](accessibility.md)。

- `⌘K` / `Ctrl+K` / `/` 開啟快速跳轉（combobox 模式），可以用中文、英文或課號搜尋課程與頁面，方向鍵選擇、Enter 開啟。
- 單鍵快捷鍵（`J`、`K`、`F`、數字鍵）可以在設定裡關掉（WCAG 2.1.4）。
- 圖示預設 `aria-hidden`，只有圖示的按鈕一定有 `aria-label`；每頁都有自己的 `<title>`；操作結果放在 `role="status"` / `role="alert"`。
- EM3 淺色主題的 success、info、warning、error 調深到文字對比 4.5:1，次要文字的透明度不低於 65%，表單邊框 3:1。課程顏色當文字或圖示時會和文字色混合（`courseText`、`courseInk`），實心底色上的字由 `readableOn` 選黑或白。
- 「減少動畫」同時停用 CSS 動畫與 transition。

## 介紹頁

沒登入時，`/` 會導到 `/welcome`；從其他網址進來的，則先到登入頁，登入後再回到原本的頁面。

- 介紹頁只用實際的產品截圖和具體的對照，例如 E3 原本的時間寫法和 EM3 的寫法。不用 eyebrow 小字、漸層文字或光暈裝飾；整頁唯一的漸層就是 logo。
- 截圖都有深淺色兩份，依目前主題切換（`<html data-scheme>`）。頁面上的主題按鈕可以直接切換主題，就是實際的設定功能。
- 截圖用 `scripts/capture-screens.mjs` 拍攝。拍攝時在 API 回應層把姓名、學號、作者換成假資料，並隱藏以人名命名的課程；如果畫面上還留有真實姓名或學號，腳本會直接中止。

## 信件

E3 的站內信（`local_dcpcmail`，改自 local_mail 外掛）可以用 API 列出、搜尋、讀取和標為未讀，但沒有寄信的 API。

- 三欄版面：資料夾（收件匣、星號、寄件備份、草稿、垃圾桶，加上本學期依課程分類）、信件列表、閱讀區。手機上一次只顯示一欄。
- 打開信件會在 E3 上標為已讀，跟在 E3 開信一樣；可以再標回未讀。
- 「回覆」和「寫信」會開 E3 對應的頁面。

## 教師與助教

依據 [教師與助教訪談](research/teacher-interviews/README.md) 的結果：

- **只給有權限的人看。** 用 `core_course_get_user_administration_options` 一次判斷所有課程裡哪些是「我在教的課」。這些課的課程頁會多一個「教學」分頁，而且會預設停在這個分頁；首頁會加一張「待批改」卡片。
- **數字以繳交紀錄為準。** 繳交和評分的數量用 submissions 加 grades 計算，不信任 E3 評分表。名單合併評分表（`list_participants`）和成績簿（`get_gradable_users`），所以選課已失效但有交的學生不會被漏掉。學號只有成績簿會給。
- **寫入一律明確、可預覽。** 逐份評分要按「儲存」或 `⌘↵`；CSV 匯入、回饋檔上傳、延長期限都會先列出要改的內容，按確認才寫入。
- **不小心清掉評語的陷阱。** Moodle 存分數時，如果沒帶評語欄位，會把它當成「評語被清空」。所以 EM3 每次存分數都會把原本的評語 HTML 原樣帶回去，只有老師真的改過評語才換成新的。只上傳回饋檔時送 `grade=-1`，會保持未評分。
- **評分工作流程。** 作業開了 marking workflow 時，會先讀出目前的狀態，再原樣送回。
- **E3 沒有 API 的就交接。** 新增教材、建立小考、刪除和排序都沒有 API。EM3 提供寫作區（Markdown 轉 HTML 一鍵複製）、小考題目編輯器（匯出 Moodle XML），以及直接打開 E3 對應表單的連結。

編輯器用 Milkdown Crepe，開啟固定的按鈕列（TopBar），給不寫 Markdown 的人用；也可以切到 Markdown 原始碼。顏色對應到 daisyUI 的主題變數，所以會跟著主題變。只在需要編輯器的頁面才延遲載入。
