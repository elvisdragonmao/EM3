EM3 の最初のバージョンです。より速く、わかりやすい Moodle のフロントエンドで、[e3.emtech.cc](https://e3.emtech.cc) を開いて学校のアカウントでログインすればすぐに使えます。

## 機能

### 学生

- **今日**：今週提出する課題をひと言で。授業中のコースには教材・課題・お知らせへのショートカットと終了までのカウントダウン。週カレンダー、締め切り間近、最近の教材、最新のお知らせ。
- **やること**：今学期のすべての課題と小テストを「期限切れ（提出可）・今日・明日・それ以降」に分け、カウントダウン付きで表示。
- **カレンダー**：週・2 週・月の 3 つの範囲。締め切りはコースの色で示し、提出済みには取り消し線。
- **お知らせ**：コースをまたいだお知らせの受信箱。既読状態はブラウザだけに記録。
- **コース**：学期ごとにまとめ、アイコンと色を自動で選択。略称の変更、ピン留め、非表示ができます。
- **教材**：ファイルが 1 つだけのフォルダを展開し、新しいものを上に表示。PDF・画像・動画はその場でプレビューでき、複数のファイルを選んで zip でダウンロードできます（大きなファイルはディスクに直接ストリーミング）。
- **提出**：ファイルをドロップして、確認して、提出。許可された形式・数・サイズは選んだ時点でチェックします。
- **小テスト**：受験履歴、問題ごとの結果と解説。教員が許可している場合は、問題をコピーして AI と相談できます。
- **時間割**：陽明交通大学のシラバスの時間コードを入力するか、マスをクリック。中正大学の授業時間は Moodle から自動で入力され、左側は学校の時間割と同じく Ⅰ–Ⅴ の区分に分かれます。
- **メール**：陽明交通大学と中正大学のサイト内メールを直接読み、検索、コース別の分類、未読に戻すことができます。

### 教員と TA

- **「授業管理」タブ**とホームの「採点待ち」カード：提出と採点の進み具合を実際の提出記録から計算し、受講登録が切れていても提出した学生を含めます。
- **採点画面**：学籍番号、フィルター、`J`/`K` で学生を切り替え、`⌘↵` で保存して次へ、コメントの定型文ライブラリ。
- **一括ツール**：学籍番号で CSV の成績を取り込み（UTF-8 と Big5 に対応）、フィードバックの zip をアップロードすると学生に自動で対応付け、ワンクリックで期限を延長、未提出者の名簿をコピー。
- **お知らせの投稿**：Milkdown エディター（ボタンまたは Markdown）。下書きは自動保存され、投稿前にプレビューできます。
- **小テストの作成**：問題エディターから Moodle XML を書き出し。**教材を書く**：Markdown を E3 に貼り付けられる形式に変換。

### 全体

- **複数の大学**：陽明交通大学、中正大学、台湾師範大学、政治大学、成功大学、銘伝大学、暨南大学、高雄大学、台南大学に対応し、ほかの大学も Moodle の URL を貼り付ければ使えます。中正大学は学校のシングルサインオン（SSO）を使います。
- **4 つの言語**：繁体字中国語、English、日本語、Emoji。既定ではシステムに合わせ、設定・ログインページ・紹介ページで切り替えられます。英語の画面では英語のコース名を優先して表示します。
- **アクセシビリティ**：WCAG 2.1 AA と台湾のウェブアクセシビリティ規範 AA を目標とし、axe の自動チェックで 4 言語・2 テーマ・22 ページすべて違反ゼロ。1 キーのショートカットはオフにできます。
- **キーボード**：`⌘K` で任意のコースへ移動、数字キーでページを切り替え、`⌘/` ですべてのショートカットを一覧表示。
- **アプリ**：ホーム画面にインストールでき、オフラインでも最後に読み込んだ内容が見られます。daisyUI のすべてのテーマに加え、EM3 独自のライトとダーク。
- **バックエンドなし**：ブラウザが学校の Moodle を直接呼び出します。パスワードはログイン用トークンの取得にだけ使います。

## 修正

- 成績の一括取り込みやフィードバックのアップロードで、一部のリクエストが失敗しても成功と表示されていました。
- フィードバックのアップロード画面に「ファイルをドロップできる」とあるのに、ドラッグ＆ドロップが動いていませんでした。
- 最初の Tab で「メインコンテンツへスキップ」が飛ばされ、言語を切り替えるとキーボードフォーカスが失われていました。
- ホームの「最近更新された教材」の日付とファイルサイズが狭い列で 1 文字ずつ折り返し、学生のホームで右の列が左より一段下がっていました（[#6](https://github.com/elvisdragonmao/EM3/pull/6)）。
- 中正大学のメールを開いても既読にならず、既読にするリクエストが失敗するとメール全体が読み込めませんでした。
- SSO のリンクが使用後 15 分以内なら、ログアウト後でも再びログインに使えました。ログインに失敗するとトークン入りのリンクがアドレスバーに残っていました。
- 時間割：ブラシを選んでいない状態で授業のあるマスで Enter を押すとその時限が消えていた、キーボードのフォーカス枠が授業ブロックに隠れていた、中正大学で Moodle から入力された時間を削除できなかった、を修正しました。
- お知らせページが幅 320 px で横スクロールしていました。文字間隔を広げると「採点待ち」のコース名が重なっていました。

中正大学のシングルサインオン、時間割、メール、ホームのレイアウト修正に貢献してくれた [@KoukeNeko](https://github.com/KoukeNeko) さんに感謝します（[#3](https://github.com/elvisdragonmao/EM3/pull/3)、[#4](https://github.com/elvisdragonmao/EM3/pull/4)、[#5](https://github.com/elvisdragonmao/EM3/pull/5)、[#6](https://github.com/elvisdragonmao/EM3/pull/6)）。
