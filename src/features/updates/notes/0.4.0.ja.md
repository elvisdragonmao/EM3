- **新しい課題・小テストの通知**。サーバー版の「設定 → 通知」で有効にできます。5 分ごとに確認し、取り組めるようになった新しい課題や小テストを Web プッシュまたは Discord で通知します。
- **締め切りリマインダー**。最後の 24 時間は 1 時間ごと、または締め切りの 15 分前、1 時間前、3 時間前、6 時間前、1 日前、3 日前、7 日前から複数選べます。通知時刻が重なった場合は 1 回だけ届きます。
- **お知らせの添付と教材**。PDF をプレビューしたり、新しいタブで開いたりできます。Word ファイルは直接ダウンロードできます。教材 ZIP のダウンロードはページを移動しても続きます。
- **メッセージ**。既読状態と未読件数の同期を修正しました。`J`／`K` でメッセージを切り替えられます。未読にしてもメッセージは開いたままです。
- **戻る操作と時間割**。新しいタブで開いた課題から、コースの課題一覧に戻れます。授業は開始時刻から「授業中」と表示されます。
- **表示**。システムのテーマに合わせて選択欄の枠線が切り替わります。ホーム画面の右上に GitHub のスターボタンとスター数を追加しました。
- **日本語**。紹介ページとログイン画面の文言、日本語フォントを更新しました。
