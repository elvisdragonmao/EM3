- **New assignment and quiz alerts**. Enable them under Settings → Reminders in the server version. Get a web push or Discord notification when new work opens. Checks run on a five-minute schedule.
- **Deadline reminders**. Choose any combination of hourly reminders on the last day and reminders 15 minutes, 1 hour, 3 hours, 6 hours, 1 day, 3 days or 7 days before a deadline. Overlapping times send one reminder.
- **Attachments and materials**. Preview announcement PDFs or open them in a new tab. Word attachments download directly. Material ZIP downloads continue when you leave the page.
- **Mail**. Read status and unread badges stay in sync. Use `J` and `K` to switch messages. Marking a message unread keeps it open.
- **Back and timetable**. Back on an assignment opened in a new tab returns to the course assignment list. Classes show as in progress from their scheduled start time.
- **Interface**. Select borders follow the system theme. The home page shows a GitHub star button and count in the upper-right corner.
- **Japanese**. Updated the landing and sign-in copy and the Japanese fonts.
