このバージョンでは ToDo がより正確になりました。メンバーが代表で提出するグループ課題を「提出不要」にでき、ローカル版でもシラバスから授業時間を取得できます。また更新履歴ページを追加し、アップデート後に初めて EM3 を開いたときに新機能をお知らせするようになりました。

## 新機能

### すべての人

- **「提出不要」にする**（両バージョン）：メンバーが代表で提出するグループ課題など、全員が提出する必要のない課題は、課題ページで「提出不要」にできます。ToDo に表示されなくなり、サーバー版では通知も止まります。一覧とカレンダーでは「提出済み」とは別のアイコンで「提出不要」と表示されます。あとで実際に提出すると「提出済み」に戻ります。
- **シラバスから授業時間を取得**（ローカル版でも利用可能に）：陽明交通大学の時間割に「シラバスから授業時間を取得」ボタンを追加しました。時間が入っていないすべての授業に、シラバスの時間と教室をまとめて入力します。ローカル版はボタンを押したときだけ授業コードを EM3 サーバーに送り、公開シラバスを調べます。アカウント情報は送られません。
- **更新履歴**：更新履歴ページを追加しました。紹介ページの上部とサイドバーからリンクしています。アップデート後に初めて EM3 を開くと、そのバージョンの新機能が表示されます。

### 教員と TA

- **「採点不要」にする**（両バージョン）：採点の必要がない課題は、採点ページで「採点不要」にできます。ホームの「採点待ち」に表示されなくなり、「授業管理」タブには「採点不要」バッジが付き、サーバー版では採点の通知も止まります。

## 改善

- 設定の「バージョン」をラジオカードにしました。ラジオボタン、強調された枠線、「使用中」バッジで、どちらを使っているかがひと目でわかります。
- ローカル版の説明を「時間割で『シラバスから取得』を押したとき以外、EM3 サーバーには接続しません」に変更しました。
