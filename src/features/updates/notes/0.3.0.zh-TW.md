這一版讓待辦清單更準：組員代交的作業可以標成「無需繳交」，本機版也能從課綱抓上課時間。另外多了更新紀錄頁，之後每次改版，登入後會先告訴你這一版有什麼新的。

## 新功能

### 所有人

- **標記「無需繳交」**（兩個版本都有）：小組作業由組員代交這類不用每個人都交的作業，可以在作業頁標成「無需繳交」。標記後不列在待辦，伺服器版也不再提醒；清單和行事曆上標「無需繳交」，跟「已繳交」用不同圖示。之後真的交了，會改回「已繳交」。
- **從課綱抓取上課時間**（本機版也有了）：陽明交大課表多了「從課綱抓取上課時間」按鈕，一次幫所有還沒有時間的課填上課綱的時間和教室。本機版只在按下按鈕時把課號送到 EM3 伺服器查公開課綱，不會送出帳號。
- **更新紀錄**：新增更新紀錄頁，介紹頁上方和側邊欄都有連結。改版後第一次打開 EM3，會跳出這一版的新功能。

### 教師與助教

- **標記「無需批改」**（兩個版本都有）：不用評分的作業可以在評分頁標成「無需批改」。標記後不列在首頁「待批改」，教學分頁標上「無需批改」，伺服器版也不再送批改提醒。

## 改進

- 設定頁的「版本」改成單選卡片，加上圓鈕、強調外框和「使用中」標籤，一眼看得出正在用哪個版本。
- 本機版的說明改成「不會連到 EM3 伺服器，除非你在課表按『從課綱抓取』」。
