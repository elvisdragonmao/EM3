This release makes your to-do list more accurate: you can mark an assignment a teammate hands in as "not needed", and the local version can now fetch class times from the syllabus. There's also a new changelog page, and from now on EM3 tells you what's new the first time you open it after an update.

## New

### Everyone

- **Mark as "not needed"** (both versions): for assignments that not everyone has to hand in, such as a group report one member submits, mark it as "not needed" on the assignment page. It leaves your to-do list, and the server version stops reminding you about it. Lists and the calendar show "not needed" with a different icon from "submitted". If you hand it in anyway, it goes back to "submitted".
- **Fetch class times from the syllabus** (now in the local version too): NYCU timetables have a "Fetch class times from the syllabus" button that fills in times and rooms for every course that has none. The local version contacts the EM3 server only when you press it, and sends nothing but course codes to look up the public syllabus. Your account isn't sent.
- **Changelog**: a new changelog page, linked from the top of the introduction page and from the sidebar. The first time you open EM3 after an update, it shows what's new.

### Teachers and TAs

- **Mark as "no grading needed"** (both versions): mark assignments that don't need grading on the grading page. They leave the "To grade" card on the home page, get a "No grading needed" badge on the Teaching tab, and the server version stops sending grading reminders for them.

## Improved

- The "Version" setting is now a pair of radio cards with a visible radio, a highlighted border and an "In use" badge, so you can tell at a glance which version you're using.
- The local version's description now reads "Never contacts the EM3 server, unless you press 'Fetch from syllabus' on the timetable".
